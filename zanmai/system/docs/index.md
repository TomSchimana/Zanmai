# Zanmai Documentation

Your head is for thinking, not for keeping track. So you put things here, they get structured and stay connected, and then Zanmai works with them: research, decisions, documents, images. Why it is built this way is in [the idea behind Zanmai](philosophy.md).

This is the documentation. You do not have to read it: ask Zanmai instead, in your own language, and it answers from these pages. Start with "show me everything I can do with Zanmai" if you are new. Every page links back here.
